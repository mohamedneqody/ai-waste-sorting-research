# بروتوكول المراجعة الثانية المستقلة لوسوم Web-Waste-Mini

**الهدف:** قياس موثوقية وسوم المجموعة عبر مراجعة بشرية مستقلة، وحساب نسبة الاتفاق بين مُقيّمين (Cohen's Kappa).

**من يراجع:** شخص واحد مختلف عن المُسمّي الأساسي (المراجعة الأولى تمت أثناء بناء المجموعة). المراجع **لا يرى التسميات المرجعية إطلاقًا قبل الانتهاء** — المراجعة عمياء بالكامل.

## المواد المجهزة (في `review_web/blind/`)

| الملف | الوصف |
|---|---|
| `blind_sheet_01..07.png` | 7 أوراق معاينة — **125 صورة مرقمة R001–R125 بترتيب مخلوط عشوائيًا (seed=42)، بلا أي تسمية ظاهرة** |
| `blind_labels.csv` | ورقة القرارات: عمود واحد تملؤه `reviewer_label` لكل رقم مراجعة |

## خطوات المراجعة (45–60 دقيقة تقريبًا)

1. افتحي الأوراق بالترتيب: `blind_sheet_01.png` ثم ما بعدها.
2. لكل صورة، حددي الفئة الواحدة الأنسب من التعريفات الآتية (نفس تعريفات المنهجية):
   - **cardboard:** الكرتون أو الصناديق الكرتونية هي المادة المسيطرة.
   - **glass:** الزجاجات أو العبوات الزجاجية هي المسيطرة.
   - **metal:** العلب أو العبوات أو الخردة المعدنية المسيطرة.
   - **paper:** الأوراق أو الجرائد أو العبوات الورقية المسيطرة.
   - **plastic:** الزجاجات أو الأكياس أو العبوات البلاستيكية المسيطرة.
   - **trash:** مخلفات مختلطة لا تملك مادة قابلة للتدوير مسيطرة بوضوح.
3. اكتبي الفئة في عمود `reviewer_label` مقابل رقم المراجعة في `blind_labels.csv`.
4. **مهم:** راجعي بترتيب الأوراق دون العودة للخلف لتصحيح قرارات سابقة (اتساق القرار الموضعي).
5. سلّمي الملف المكتمل — **بعدها فقط** يُحسب الاتفاق ويُكشف التسميات المرجعية.

## حساب الاتفاق (ينفذه المهندس بعد التسليم)

- **نسبة الاتفاق الخام:** عدد الصور المتفَق عليها ÷ 125.
- **Cohen's Kappa:** اتفاق معدّل بالصدفة — يُعرض مع تفسيره المعتاد (≤0.40 ضعيف، 0.41–0.60 معتدل، 0.61–0.80 جيد، ≥0.81 ممتاز).
- يُدرج في البحث ضمن قسم موثوقية الوسوم (3-3 أو 7-4) بالأرقام الفعلية فقط.

# استبيان مصغر — معرفة الفرز داخل البيئة الجامعية (اختياري)

> **الإطار المنهجي:** استبيان وصفي قصير لعينة ملائمة (Convenience Sample) من 15–30 طالبًا. لا يدعي التمثيل الإحصائي لأي مجتمع، والنتائج تُعرض بوصفها سياقًا مساندًا لدراسة الفرز داخل البيئة الجامعية فقط.
> **مدة التعبئة:** أقل من دقيقة. **بلا أسماء أو بيانات تعريفية إطلاقًا.**

## الأسئلة الستة (جاهزة للصق في Google Forms)

**عنوان النموذج:** استبيان قصير: الفرز وإعادة التدوير داخل الجامعة (مجهول الهوية)

1. **هل تعرف ألوان حاويات الفرز الموجودة في الجامعة؟**
   نعم وأستخدمها / نعم لكن لا أستخدمها / لا أعرفها / لا توجد حاويات فرز أصلًا

2. **هل سبق أن فرزت مخلفاتك (بلاستيك/ورق/زجاج) قبل التخلص منها؟**
   دائمًا / أحيانًا / نادرًا / أبدًا

3. **أي المخلفات الأتيان أصعب لك في تحديد حاويتها الصحيحة؟** (اختر واحدًا)
   العبوات البلاستيكية الشفافة / الزجاج / العلب المعدنية / الورق والكرتون / المخلفات المختلطة / لا يوجد صعوبة

4. **لو وُجد تطبيق تصوّر فيه المخلف فيخبرك فورًا بالحاوية الصحيحة، هل سيساعدك؟**
   سيساعد كثيرًا / سيساعد قليلًا / لن يغير شيئًا

5. **ما أكبر عائق أمام الفرز في الجامعة؟** (اختر واحدًا)
   قلة الحاويات / عدم وضوح التعليمات / ضيق الوقت / عدم وجود دافع / لا يوجد عائق

6. **اقتراح حر (اختياري):** ما الذي يجعل الفرز أسهل داخل الجامعة؟
   (فقرة نصية قصيرة)

## إعدادات النموذج

- **اقفلي** خيار «جمع عناوين البريد الإلكتروني» (مجهول الهوية).
- فعّلي «عرض شريط التقدم».
- بعد إغلاق الاستبيان: نزّلي الردود CSV وأرسليها — التحليل الإحصائي الوصفي (نسب + رسوم) يُنفَّذ آليًا ويدخل البحث كسياق مساند مع تصريح العينة الملائمة.

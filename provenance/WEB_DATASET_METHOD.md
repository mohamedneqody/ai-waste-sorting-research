# WEB_DATASET_METHOD.md — منهجية بناء مجموعة Web-Waste-Mini

**تعريف المجموعة:** «مجموعة صور ويب عامة موثقة لاختبار التعميم الخارجي لنموذج مدرب على TrashNet».

## 1) طبيعة المجموعة
- Web-Waste-Mini مجموعة اختبار خارجية مستقلة مبنية بالكامل من **صور ويب عامة مرخصة**، تختلف بنيويًا عن بيانات التدريب من نوع TrashNet في الخلفيات وظروف الإضاءة وزوايا الالتقاط وتباين المشاهد، وهذا هو الغرض: قياس التعميم الخارجي.
- المجموعة **مجموعة ويب عامة، وليست مجموعة ميدانية محلية أو جامعية**؛ كل صورة لها صفحة ملف أصلية على Wikimedia Commons مع رخصة معلنة ومؤلف مسجل.
- لا تحتوي أي صور مولّدة بالذكاء الاصطناعي، ولا أي صور من TrashNet أو مستودعه الأصلي أو أي نسخة معاد نشرها منه (فُحصت أوصاف المصادر صراحة ضد ذلك).

## 2) المصدر والترخيص
- **المصدر الوحيد:** Wikimedia Commons، عبر MediaWiki API الرسمي (استعلامات `search` على نطاق الملفات + `categorymembers` لتصنيفات سياقات إدارة المخلفات في مصر).
- **الترخيصات المقبولة فقط:** CC0، Public Domain، CC BY (كل الإصدارات)، CC BY-SA (كل الإصدارات). رُفض آليًا أي مرشح بترخيص NC/ND/GFDL-only/غير معلن.
- **لا يُستخدم Google Images كمصدر أصل**؛ رابط التنزيل المسجل في المانيفست هو الرابط الفعلي المستخدم (نسخة أصلية أو نسخة عالية الجودة بعرض حتى 1600 بكسل عبر نقطة `thumb.php` الرسمية) مع صفحة المصدر الأصلية في عمود مستقل.
- التراخيص الفعلية في المجموعة النهائية: CC BY-SA 4.0 (46)، Public Domain (20)، CC BY 2.0 (17)، CC BY-SA 3.0 (10)، CC0 (11)، CC BY 4.0 (9)، CC BY 3.0 (6)، CC BY-SA 2.0 (5)، CC BY 2.5 (1).

## 3) معايير القبول والاستبعاد
**قواعد الاستبعاد الصارمة (تطبق قبل التنزيل آليًا ثم بصريًا على كل صورة):**
1. وجه بشري واضح قابل للتعرف في أي مكان بالإطار (بما فيه الوجوه المطبوعة الواضحة في الملصقات).
2. ظهور لوحة سيارة (تُستبعد حتى لو كانت الأحرف غير مقروءة).
3. رقم هاتف أو بطاقة شخصية أو عنوان أو اسم شخصي مقروء في أي نص داخل الصورة (بما فيه الأرقام التجارية المطبوعة على الصناديق).
4. علامة مائية أو نص كبير متراكب أو شعار محقوق على الصورة (نصوص المشهد الطبيعية مثل ملصق القارورة أو لافتة المحل ليست علامة مائية).
5. مخطط أو إنفوجرافيك أو كولاج أو رسم/توضيح أو ما يشبه الصور المولدة.
6. قطع متحفية/أثرية، وثائق ومراسلات أرشيفية، وصور كتالوج — ليست مخلفات.
7. حاويات فارغة بلا مادة مخلفات ظاهرة، ومركبات جمع بلا مخلفات مرئية — ليست مادة مخلفات.
8. تكرار تام (SHA-256 أو SHA-1 للمصدر) أو تكرار بصري قريب (بصمات aHash/dHash) أو زوايا متعددة لنفس المشهد/العنصر — تُقبل نسخة واحدة فقط.
9. جودة رديئة (ضباب حاد/تلف).
10. أبعاد صغيرة (< 500×400) أو نسبة أبعاد متطرفة (> 2.8) أو صيغ غير فوتوغرافية.

**قاعدة عدم التخمين:** أي شك في المادة أو الترخيص أو وجود بيانات شخصية يُحسم بفحص النسخة الكاملة الدقة قبل القرار؛ وما تعذر حسمه يُعلَّم `needs_human_review` ولا يُنسخ إلى مجلد الفئة (الحالات المعلقة النهائية: 0 — انظر COLLECTION_REPORT.md).

## 4) تعريف الفئات
- **cardboard:** كرتون أو صناديق كرتون مستعملة/مضغوطة وهي المادة المسيطرة.
- **glass:** زجاجات أو عبوات زجاجية (فوارغ/مكسرة/مجمعة) مسيطرة.
- **metal:** علب أو عبوات أو خردة معدنية واضحة مسيطرة.
- **paper:** أوراق أو جرائد أو مجلات أو دفاتر أو عبوات ورقية مسيطرة.
- **plastic:** زجاجات أو أكياس أو عبوات بلاستيكية مسيطرة.
- **trash:** مخلفات مختلطة أو عامة لا تملك مادة قابلة لإعادة التدوير مسيطرة بوضوح.
قاعدة عامة: التسمية تتبع **المادة المسيطرة فعليًا في الصورة** وليس استعلام البحث الذي جاءت منه.

## 5) إجراءات الجمع والفحص (خط التنفيذ)
1. **جمع المرشحين:** 110 استعلامات بحث/تصنيف ناجحة على 7 جولات جمع أعادت ~1400 نتيجة خام، وخُلّصت إلى 1229 مرشحًا فريدًا بعد فلترة الترخيص والصيغة والأبعاد والعناوين (مع إزالة التكرار عبر SHA-1 الخاص بالمصدر).
2. **التنزيل والتجهيز:** نُزّل 471 مرشحًا أولويةً للسياقات المصرية الموثقة ثم بتنويع بين الاستعلامات؛ اكتمل 410 ولم يكتمل 61 (أخطاء شبكة/تكرارات بصرية). لكل صورة: حساب SHA-256، بصمة إدراكية (aHash/dHash بمسافة هامينج) لرفض التكرار القريب قبل الفحص، صورة معاينة للفحص، وفحص EXIF.
3. **الفحص البصري متعدد الجولات (7 جولات جمع/فحص):** كل صورة فُحصت فرديًا — مراجعة أولى منظمة (فئة/وجه/لوحة/بيانات شخصية/علامة مائية/مخطط/مشهد/شفافية/جودة/تكرار)، ثم **مراجعة يدوية بالدقة الكاملة** لكل الحالات الحدية (53 حالة)، ثم **بوابة جودة نهائية على لوحات المعاينة (Contact Sheets) خليةً خلية** أدت إلى استبعاد 36 صورة إضافية، إضافة إلى فحص QA لعينات ومسح عناوين كل المقبولات ضد كلمات (museum/ancient/artifact...) الذي استبعد 6 صور أخرى.
4. **توثيق السياق المصري:** تُوسم `egypt_public` فقط إذا أثبتت بيانات المصدر (الوصف أو التصنيفات على صفحة الملف) موقعًا مصريًا (مصر/القاهرة/الإسكندرية/الزبالين/منشية ناصر/...). مع حواجز ضد الإيجابيات الكاذبة: «Egyptian Vulture» (طائر)، صور تحف مصرية داخل متاحف خارج مصر، ومنشأة «Suez recycling» في برمنغهام. غير ذلك تُوسم `global_public`.
5. **الخصوصية على النسخ المحلية:** صورة واحدة كانت تحمل إحداثيات GPS داخل EXIF فأُعيد ترميزها محليًا بدون EXIF (موثق في عمود notes).
6. **التسمية:** أسماء ملفات محايدة متسلسلة `wwm_NNNN` داخل مجلد الفئة؛ المانيفست يربط كل معرف بصفحة المصدر ورخصته.

## 6) وسوم المشهد والصعوبة
- `scene_type`: **single** (عنصر مسيطر على خلفية بسيطة) = 44، **crowded** (أكوام/شوارع/حاويات متعددة) = 81.
- `difficulty`: **normal** = 111، **transparent_hard** (المادة الشفافة مسيطرة ويصعب تمييزها: زجاج شفاف، أكياس شفافة، قوارير شفافة) = 14.

## 7) بنية الملفات
```
data/web_waste_mini/
  cardboard/ glass/ metal/ paper/ plastic/ trash/   ← wwm_NNNN.jpg
provenance/
  web_waste_manifest.csv      ← صف لكل صورة فُحصت (مقبولة/مرفوضة) بكل أعمدة التوثيق
  WEB_IMAGE_ATTRIBUTION.md    ← سطر إسناد لكل صورة مقبولة
  COLLECTION_REPORT.md        ← الأعداد والاستبعادات والفجوات
review_web/
  contact_sheet_<category>.png ← لوحات معاينة شبكية لكل فئة
  unclear_report.md            ← الحالات غير الواضحة
```
أعمدة المانيفست: image_id, image_path, true_label, source_context, source_page_url, direct_download_url, license, creator, attribution, accessed_at, location_evidence, scene_type, difficulty, sha256, review_status, notes.
صفوف بـ review_status=accepted هي عناصر المجموعة الفعلية؛ صفوف rejected سجل تدقيق بلا ملفات صور محفوظة.

## 8) الفصل عن بقية المشروع
- لم تُخلط هذه الصور مع أي مجموعة بيانات أخرى في المستودع، ولم يُنشأ أي ملف خارج المسارات أعلاه.
- لم يُعدَّل النموذج ولا قاعدة SQLite ولا مسودة البحث، ولم يُشغَّل أي سكربت تقييم.

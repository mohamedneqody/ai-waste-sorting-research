## ترتيب اليوم من 4 (المتبقي من الخطة)

1. **انتي:** تجمعي 100–150 صورة حسب البروتوكول (يومين) + تسألي الإدارة عن معايير التحكيم وبيانات الاستمارة.
2. **انتي (اختياري):** مفتاح Gemini مجاني من Google AI Studio.
3. **أنا:** أول ما الصور توصل → تقييم فوري → رسوم المقارنة → **كتابة البحث كاملًا** (الفصل الخامس = قلبه محتاج أرقام تجربتك) → تنسيق PDF.

### إعادة إنتاج النتائج بالترتيب

```bash
python scripts/train_model.py          # التدريب الداخلي → models/metrics.json + charts/
python scripts/evaluate_webset.py      # التقييم الخارجي → results/webset/
python scripts/evaluate_gemini_webset.py   # بعد ضبط GEMINI_API_KEY (متغير بيئة فقط)
python scripts/compare_webset.py       # جدول المقارنة النهائي
python prototype/app.py                # النموذج الأولي (127.0.0.1:5050)
```
